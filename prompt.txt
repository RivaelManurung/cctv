# CCTV INDONESIA — Production-Grade CCTV Aggregator

Build a **production-quality, highly polished CCTV Indonesia web application** using **Next.js + TypeScript**.

The application is a frontend-only platform that aggregates publicly available CCTV / traffic camera sources across Indonesia.

The goal is to make the application feel like a real commercial product, **not a simple CRUD demo or static HTML page**.

---

# 1. TECHNOLOGY STACK

Use:

- Next.js latest stable
- TypeScript
- App Router
- React
- Tailwind CSS
- shadcn/ui
- Lucide React
- Leaflet + React Leaflet OR MapLibre GL JS for maps
- Zustand for client-side state where appropriate
- Zod for validating static CCTV data
- date-fns for date/time formatting
- next-themes for dark/light mode
- Sonner for notifications

Do NOT use:

- Database
- Prisma
- Supabase
- Firebase
- Laravel
- Express
- Separate backend
- Authentication server
- Server-side database
- CMS

Everything must work from the frontend.

---

# 2. DATA ARCHITECTURE

Since there is no database, create a strongly typed static data architecture.

Use:

```text
src/
├── data/
│   ├── cctv.ts
│   ├── provinces.ts
│   ├── cities.ts
│   ├── categories.ts
│   └── sources.ts
```

CCTV data must be represented using TypeScript interfaces.

Example:

```ts
export interface CCTV {
  id: string
  name: string
  slug: string

  province: string
  provinceSlug: string

  city: string
  citySlug: string

  district?: string
  address?: string

  latitude: number
  longitude: number

  category:
    | "traffic"
    | "road"
    | "intersection"
    | "highway"
    | "public-space"
    | "port"
    | "airport"
    | "other"

  streamType:
    | "hls"
    | "mjpeg"
    | "iframe"
    | "image"
    | "youtube"
    | "external"

  streamUrl?: string
  thumbnailUrl?: string

  sourceName: string
  sourceUrl: string

  status: "online" | "offline" | "unknown"

  description?: string

  isFeatured?: boolean

  tags?: string[]

  lastChecked?: string

  metadata?: {
    direction?: string
    road?: string
    operator?: string
  }
}
```

DO NOT scatter CCTV objects throughout components.

All cameras must come from the centralized data layer.

---

# 3. IMPORTANT DATA RULE

Do not invent fake live CCTV URLs.

If a real public CCTV stream is unavailable, use:

```ts
streamType: "external"
```

and provide the official source URL.

Clearly distinguish:

```text
LIVE
EXTERNAL
OFFLINE
UNAVAILABLE
```

Never pretend that a non-live source is a live camera.
